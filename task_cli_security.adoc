= 變更 Deploy 管理員密碼

您可以根據需要使用命令列介面變更 Deploy 虛擬機器管理員帳戶的密碼。

.步驟
. 使用管理員帳戶 Sign in 至部署實用程式 CLI。
. 變更密碼：
`password modify`
. 根據您的環境適當回應所有提示。
